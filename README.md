# 年糕的像素冒险

李念（年糕）的个人介绍与摄影作品集。GBA 风格的原创像素场景、真实风光摄影、可播放的展示段落。

## 使用

个人介绍与相册可直接打开 `index.html`，或部署静态文件至 GitHub Pages，无需构建工具或 CDN。结尾的年糕.Agent 对话需要年糕电脑上的服务与 HTTPS 连接保持在线。

- 8 个关卡：开场、档案、项目、宝可梦、游戏、摄影、成长、联系。
- 7.8 秒可跳过开场；18 秒冒险序章；12 秒项目流程；10 秒工具调用；30 秒风光短片。
- 演示可暂停；导航和打开弹窗会停止当前播放，避免叠加。
- 照片保留自然色彩与构图，提供等比压缩展示副本，已移除 EXIF/GPS 元数据。
- 支持手机、键盘、减少动态效果；声音默认关闭，仅按用户操作生成短提示音。
- 按 P 打开演讲笔记；隐藏秘技：↑↑↓↓←→←→BA，或连点「年糕」三次。

## 年糕.Agent

《我把自己蒸馏成一个Agent》是人设提示词作品，不是真正训练或微调。它模拟年糕的公开语气与兴趣，不是本人在线。

网页 → HTTPS 隧道 → 年糕电脑的 API-only 网关 → 电脑上的服务 → 模型供应商。网页不包含 API Key。

- 仅用户主动发送才调用模型；任何循环展示不调用聊天接口。
- 最近历史只在当前页面内存中，回复和问题不落盘。短轮询回复片段在服务器内存暂存，最多150秒，供同一访客取回；限额计数另行持久化。
- 目前每位访客每分钟最多6次、每天30次；全站每日150次，发起的失败/停止请求也占一次计数，生成长度另有限制。这是请求额度，不是金额预算。
- 支持停止生成、重开对话、显式重试；已取消、未完成或截断的回复不进入下轮历史。
- 临时隧道不保证持续在线，电脑休眠/关机或连接停止后对话不可用，图片与介绍仍可浏览。
- 临时隧道不支持SSE，访客端使用短轮询实际回复片段；本机页面保留SSE。稳定上线应改用固定域名命名隧道与更完善的防滥用措施。

服务源码、人设与运行密钥不随 GitHub Pages 发布；网站仓库只发布前端。
